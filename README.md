# Journal

A customizable journal that adapts to what you track — not the other way around.

No backend. No accounts. Your data stays in your browser.

---

## How it works

1. Go to **Settings** → create a template with the fields you need
2. Set a default template for quick entry
3. Start writing

That's it.

---

## What you can track

Anything with structure + notes:

- Trades (entry, exit, reason, P&L)
- Workouts (exercise, sets, reps, weight)
- Expenses (category, amount, date)
- Mood (sleep, energy, stress, notes)
- Meetings (attendees, decisions, action items)

You design the fields. The journal just stores them.

---

## Features

- Custom templates — name, field types (text, number, date, textarea)
- Quick Entry — uses your default template, shows first 3 fields
- Search + filters (template, date range)
- Pin important entries
- Expand/collapse entries
- 5 themes (Light, Sepia, Forest, Midnight Blue, Red Ember)
- Keyboard shortcuts: `N` (new), `Esc` (close), `Ctrl+S` (save)
- Undo last edit on any entry
- Export/import templates
- Full data backup/restore

---

## Running locally

Download or clone the repo, then open `index.html` in your browser.

No build step. No dependencies.

---

## Data storage

Everything stays in your browser's localStorage. Export a backup if you want to save it elsewhere.

---

## Why this exists

Most journal apps force you into their structure. This one doesn't.
